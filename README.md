A deterministic Node program that writes one line to `/output/entry.txt`: the funniest last words a phone says as its battery hits 1 percent — in the phone's own voice, tight, with the punch landing at the end. The line is 132 characters, a single line with no trailing newline, well within the 1–199 character gate.

## Run it

```sh
node main.ts
```
